# Морской бой
   **Демо:** https://battleship-x0ht.onrender.com
Минималистичная браузерная игра «Морской бой» с ИИ разной сложности, онлайн-матчами по ссылке, магазином скинов, статистикой и разбором партии. Проект сделан для второго этапа отбора Narxoz Incubator 2026 (задание «Морской бой»).

## Для кого и чем отличается
Для студентов, которым нужна быстрая партия на перемене: без регистрации, с телефона и с ноутбука. Особенности:
- **Расстановка перетаскиванием** (мышь и палец) с подсветкой допустимых клеток.
- **Вероятностный ИИ**: сложный уровень считает плотность вероятностей по оставшимся кораблям.
- **ИИ-Тренер**: после партии разбирает каждый выстрел и даёт советы.
- **Честный онлайн**: SHA-256 хеш расстановки, сверка в конце партии.
- **Продуктовый слой**: монеты, скины, Pro (тестовый режим), лиги и друзья.

## Правила
Поле 10×10, флот: один 4-палубный, два 3-палубных, три 2-палубных, четыре 1-палубных. Корабли не могут касаться друг друга, в том числе по диагонали. При попадании игрок стреляет снова, при промахе ход переходит. Победитель тот, кто первым потопил весь флот. В клетку нельзя стрелять дважды.

## Запуск
```bash
npm install
npm start      # http://localhost:3000
```
Деплой (Render/Railway): Build `npm install`, Start `npm start`. Порт берётся из `PORT`.

## Структура
- `server.js` — Express + Socket.io: комнаты на 2 игрока, пересылка ходов.
- `public/` — фронтенд (`index.html`, `styles.css`, `app.js`), без сборщика.

## Технологии и инструменты
Node.js, Express 5, Socket.io 4, чистые HTML/CSS/JS, localStorage, Web Crypto API (SHA-256), SVG для графика. AI-инструменты: Claude (Anthropic) — помощь в написании и правке кода; решения проверены и поняты автором.

## Заимствованные компоненты
Сторонние библиотеки: только Express, Socket.io и cors (npm). Шаблоны и UI-киты не использовались, дизайн и код написаны для этого проекта.

## Известные ограничения
- Платежей нет: Pro и покупка монет работают в тестовом режиме, монеты за деньги помечены «Скоро».
- Лиги и рейтинг других игроков — демо-данные; друзья и статистика хранятся локально в браузере (нет авторизации и общей базы).
- Сервер — «посредник»: он не проверяет ходы, читерство обнаруживается в конце партии по хешу.
- Комнаты хранятся в памяти сервера; при перезапуске сервера онлайн-партии сбрасываются. После перезагрузки страницы в онлайн-партии роль выдаётся заново.

## Как это работает (фрагменты кода)

**1. Игровой цикл.** Выстрел и проверка расстановки (`G.shoot`, `G.fits` в `public/app.js`):
```js
shoot(b,i){ if(b.shots[i]) return null;      // повторный выстрел запрещён
  const s=b.ships.find(s=>s.includes(i));
  if(!s){ b.shots[i]=1; return {r:"miss"} }
  b.shots[i]=2;
  if(G.sunk(b,s)){ G.halo(b,s); return {r:"sunk",ship:s} }
  return {r:"hit"} }
```

**2. Вероятностный ИИ.** Сложный уровень считает вес каждой клетки по всем вариантам размещения оставшихся кораблей (сокращённо):
```js
for(const n of G.rem(b))
 for(let i=0;i<100;i++) for(const h of [true,false]){
  const ids=...cellsOf(i,n,h);
  if(ids.some(j=>промах||потоплен)) continue;
  const k=ids.filter(j=>b.shots[j]==2).length;   // попадания внутри варианта
  ids.forEach(j=>{ if(!b.shots[j]) w[j]+=1+k*25 }) }
```

**3. ИИ-Тренер.** Каждый выстрел сравнивается с лучшей клеткой на тот момент (`q=1` — лучший ход):
```js
const w=G.weights(b);
rows.push({ k:k+1, i:m.i, q:w[m.i]/mx });
G.shoot(b,m.i);
```

**4. Защита от читерства.** Перед боем отправляется только хеш, в конце флот раскрывается и проверяется:
```js
S.hash = await sha(JSON.stringify(S.pl.ships) + S.salt);
socket.emit("sb_ready", { h: S.hash });
S.ver = (await sha(JSON.stringify(m.ships) + m.salt)) == S.oppHash ? 1 : 0;
```
