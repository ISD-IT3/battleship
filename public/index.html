1. Полноценный игровой цикл

От расстановки флота перетаскиванием до победителя: проверка касаний кораблей, запрет повторных выстрелов, потопление с обводкой, статистика.

shoot(b,i){ if(b.shots[i]) return null;      // повторный выстрел запрещён
  const s=b.ships.find(s=>s.includes(i));
  if(!s){ b.shots[i]=1; return {r:"miss"} }
  b.shots[i]=2;
  if(G.sunk(b,s)){ G.halo(b,s); return {r:"sunk",ship:s} }
  return {r:"hit"} }

fits(b,cs){ if(cs.some(([r,c])=>r>9||c>9)) return false;   // за границей поля
  const o=new Set(b.ships.flat());
  return cs.every(([r,c])=>[r*10+c,...G.nb(r*10+c)].every(j=>!o.has(j))) } // без касаний

2. Вероятностный ИИ (Probability Density)

На сложном уровне строится матрица весов: перебираются все допустимые положения оставшихся кораблей, клетки рядом с попаданием получают больший вес. ИИ стреляет в клетку с максимальным весом.

for(const n of G.rem(b))                        // оставшиеся корабли

3. ИИ-Тренер

После партии каждый ваш выстрел сравнивается с лучшей клеткой на тот момент. Получаются точность, тактический индекс, главные ошибки и карта выстрелов (зелёный, жёлтый, красный).

mv.forEach((m,k)=>{
  const w=G.weights(b);                  // веса в тот момент партии
  let mx=0; w.forEach((v,i)=>{ if(!b.shots[i]&&v>mx) mx=v });
  rows.push({ k:k+1, i:m.i, q:w[m.i]/mx });   // q=1 — лучший возможный ход
  G.shoot(b,m.i);                        // повторяем партию дальше
});
// q >= .6 зелёный · q >= .3 жёлтый · иначе красный

4. Защита от читерства

Онлайн через Socket.io. Перед боем игрок отправляет только SHA-256 хеш расстановки с солью, в конце раскрывает флот, и соперник сверяет хеш. Изменить расстановку по ходу партии не получится.

// перед боем: отправляем только хеш
S.hash = await sha(JSON.stringify(S.pl.ships) + S.salt);
socket.emit("sb_ready", { h: S.hash });

// в конце партии: соперник раскрыл флот и соль — проверяем
S.ver = (await sha(JSON.stringify(m.ships) + m.salt)) == S.oppHash ? 1 : 0;

Структура

  • server.js: комнаты на 2 игрока, сервер не хранит чужие расстановки и только пересылает ходы.
  • public/app.js: логика G отдельно от отображения, страницы, перетаскивание (Pointer Events), онлайн.
  • localStorage: партия, статистика, монеты, скины.
